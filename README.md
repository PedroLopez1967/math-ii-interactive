# Matemática II Interactiva – UNA

**Demo:** https://math-ii-interactive.vercel.app

Aplicación web interactiva para el curso **Matemática II (Cálculo)** de la Universidad Nacional Abierta (UNA), Venezuela. Está pensada para estudiantes de educación a distancia que necesitan practicar por su cuenta, con explicaciones paso a paso y pistas.

*Interactive web app for UNA's Mathematics II (calculus) course: step-by-step worked problems with hints and difficulty levels, designed for distance-learning students.*

## Contenido

| Objetivo | Temas |
|---|---|
| I.1 | Límites mediante cambio de variable |
| I.2 | Límites especiales y trigonométricos |
| I.3 | Límites laterales, continuidad y teorema del valor intermedio |
| II.1 | Derivada por definición y reglas de derivación |

## Características

- Problemas resueltos paso a paso
- Sistema de pistas
- Niveles de dificultad
- Gráficas interactivas
- Seguimiento del progreso

## Tecnologías

React, TypeScript, Vite, Tailwind CSS, Recharts, math.js. Desplegada en Vercel.

## Ejecutar en local

Requiere Node.js 18 o superior.

```bash
git clone https://github.com/PedroLopez1967/math-ii-interactive.git
cd math-ii-interactive
npm install
npm run dev
```
